# Generated outputs

This directory contains released OTTER artefacts and files generated by the analysis pipeline.
Large files are downloaded with `python scripts/fetch_data.py`; see [`DATA.md`](../DATA.md) for
archive contents, source provenance and licensing.

## Canonical coupling

`coupling/pi_canonical.npy` is the released coupling and the default returned by `load_pi()`. It
has shape 1,864 mouse parcels × 2,094 human parcels. Its entries are transport weights; normalise
a row before interpreting it as a distribution over human targets.

Other `pi_*.npy` files are inputs to specific sensitivity or comparison analyses. New applications
should use `load_pi()` unless a named alternative is explicitly required.

## Directory layout

| Path | Contents |
|---|---|
| `anndata/` | Processed mouse and human parcel tables and cached cost matrices |
| `coupling/` | Couplings, bootstrap summaries and interface display metadata |
| `logs/` | Machine-readable analysis results and coupling provenance |
| `comparison/` | Tables generated by comparative analyses |
| `figures/` | Generated static and interactive figures |
| `gui/` | Self-contained mapping explorer and its JSON data |
| `audit/` | Machine-readable integrity checks for released artefacts |

`coupling/trust_multisource_canonical.npz` contains the fields used to assign the explorer's five
display categories. The categories combine Garin-landmark or regional-entry membership,
Beauchamp benchmark-region membership and internal stability summaries. They are heuristic
interface metadata, not calibrated confidence scores or estimates of parcel-level correctness.

Result logs identify the coupling used to generate them through a filename and SHA-256 hash.
Use `pi_provenance()` or the helpers in `otter.repro` to verify that a log and coupling match.

## Rebuilding the explorer

```bash
PYTHONPATH=src python pipeline/08_build_gui.py --publish
```

This reads the released display-metadata file, writes `outputs/gui/index.html` and publishes the
self-contained copy to `docs/index.html`.
